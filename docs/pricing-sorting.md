# 定价页排序

`GET /api/pricing` 的每个模型返回 `created_time`（Unix 秒）：取自匹配的 `models` 记录，`0` 表示未知。这是本地目录记录创建时间，不是厂商发布日期或渠道首次启用时间；规则匹配的模型共用该规则记录的时间。编辑记录不会重置创建时间，无记录时不补造时间。

- 两主题提供名称、价格升序、价格降序、最新上架、最早上架五种排序，默认按名称。
- Classic 仅表格模式在搜索框右侧显示排序菜单；卡片保持原有顺序。计费类型列排序仍可用，选择菜单会清除列排序。
- Default 的卡片和表格共用工具栏排序。
- 上架时间缺失、为零或无效时始终置后；同时间按模型名称升序。旧后端没有该字段时退化为名称排序。
- 先筛选和排序完整列表，再分页；切换排序回到第一页，不清除勾选或筛选条件。
- 价格排序沿用 Default 原有口径：按量模型比较 `model_ratio`，按次模型比较 `model_price`（缺失为零），不新增价格换算。

该变更仅增加响应字段，不新增数据库列、排序请求参数或外部数据源；旧前端可忽略该字段，回退前端无需回滚数据库。
